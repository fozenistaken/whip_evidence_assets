# GTA V Enhanced

These are the props from `stream/`, converted for FiveM for GTA V Enhanced with Cfx.re's Alchemist.

On an Enhanced server, delete `stream/` and rename this folder to `stream_enhanced/`. Keep only one of the two: a
resource with both fails to start on Enhanced ("Failed to generate cache for set: resource.rpf",
[citizenfx/rfc#477](https://github.com/citizenfx/rfc/discussions/477)).

On FiveM Legacy, leave everything as it is.
